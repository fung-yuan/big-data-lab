⚙️ Hadoop MapReduce Lab

Step-by-step guide to set up your WordCount project

Prerequisites

Before starting, ensure you have the following installed:

  • Java JDK 8 or higher
  • Apache Maven
  • Docker (for Hadoop cluster)
  • VS Code with Java extensions

Project Structure

📁 hadoop-labs/
  📁 wordcount/
    📄 pom.xml
    📁 src/main/java/hadoop/mapreduce/tp1/
      📄 TokenizerMapper.java
      📄 IntSumReducer.java
      📄 WordCount.java
    📁 src/main/resources/input/
      📄 file.txt

Step 1: Create Project Structure

Open PowerShell and run:

PowerShell
# Navigate to workspace
cd C:\Users\YourUser\Desktop

# Create project directories
mkdir -p hadoop-labs\wordcount\src\main\java\hadoop\mapreduce\tp1
mkdir -p hadoop-labs\wordcount\src\main\resources\input

Step 2: Create pom.xml

Create wordcount/pom.xml with dependencies and shade plugin:

pom.xml
<?xml version="1.0" encoding="UTF-8"?>
<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 
         http://maven.apache.org/xsd/maven-4.0.0.xsd">
    <modelVersion>4.0.0</modelVersion>
    <groupId>hadoop.mapreduce</groupId>
    <artifactId>wordcount</artifactId>
    <version>1.0-SNAPSHOT</version>

    <properties>
        <maven.compiler.source>8</maven.compiler.source>
        <maven.compiler.target>8</maven.compiler.target>
    </properties>

    <dependencies>
        <dependency>
            <groupId>org.apache.hadoop</groupId>
            <artifactId>hadoop-common</artifactId>
            <version>3.3.6</version>
        </dependency>
        <dependency>
            <groupId>org.apache.hadoop</groupId>
            <artifactId>hadoop-mapreduce-client-core</artifactId>
            <version>3.3.6</version>
        </dependency>
        <dependency>
            <groupId>org.apache.hadoop</groupId>
            <artifactId>hadoop-hdfs</artifactId>
            <version>3.3.6</version>
        </dependency>
        <dependency>
            <groupId>org.apache.hadoop</groupId>
            <artifactId>hadoop-mapreduce-client-common</artifactId>
            <version>3.3.6</version>
        </dependency>
        <dependency>
            <groupId>org.apache.hadoop</groupId>
            <artifactId>hadoop-mapreduce-client-jobclient</artifactId>
            <version>3.3.6</version>
        </dependency>
    </dependencies>

    <build>
        <plugins>
            <plugin>
                <groupId>org.apache.maven.plugins</groupId>
                <artifactId>maven-shade-plugin</artifactId>
                <version>3.5.1</version>
                <executions>
                    <execution>
                        <phase>package</phase>
                        <goals><goal>shade</goal></goals>
                        <configuration>
                            <transformers>
                                <transformer implementation="org.apache.maven.plugins.shade.resource.ManifestResourceTransformer">
                                    <mainClass>hadoop.mapreduce.tp1.WordCount</mainClass>
                                </transformer>
                                <transformer implementation="org.apache.maven.plugins.shade.resource.ServicesResourceTransformer"/>
                            </transformers>
                        </configuration>
                    </execution>
                </executions>
            </plugin>
        </plugins>
    </build>
</project>

Step 3: Build the Project

PowerShell
cd hadoop-labs\wordcount
mvn clean package
💡 Tip

The shade plugin creates a fat JAR with all dependencies bundled.

Step 4: Deploy to Hadoop Cluster

1

Copy JAR to Docker container

docker cp target/wordcount-1.0-SNAPSHOT.jar hadoop-master:/root/wordcount.jar
2

Connect to master node

docker exec -it hadoop-master bash
3

Set up HDFS input

# Create input directory
hdfs dfs -mkdir -p /data/tp1/input

# Upload your data file
hdfs dfs -put corpus.txt /data/tp1/input/
4

Run the MapReduce job

hadoop jar /root/wordcount.jar /data/tp1/input /data/tp1/output
5

View the results

hdfs dfs -cat /data/tp1/output/*

Monitor Your Job

Access the YARN Resource Manager UI at:

http://localhost:8088
